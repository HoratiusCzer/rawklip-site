Rawklip Privacy Policy

Last updated: October 14, 2026

Who uses Rawklip

Rawklip is a personal tool. It is used only by me, the owner of the Rawklip YouTube channel, on my own computer. It is not offered to anyone else, and no other people sign in to it.

What Google and YouTube access is used for

When I connect my own Google account, Rawklip uses that access only to:

  • upload videos (YouTube Shorts) to my own YouTube channel, with their titles, descriptions and tags;
  • read my own channel's details and videos;
  • read my own channel's YouTube Analytics (for example views and watch time), so I can see how my Shorts perform.

It does not access anyone else's account, channel or data.

Sharing

Rawklip does not share, sell or transfer any Google or YouTube user data to anyone. The data is used only for the purposes listed above.

Storage

The sign-in tokens and any channel data Rawklip reads are stored only on my own computer, in a local database. They are not stored on any server or in the cloud.

Removing access and data

Access can be removed at any time in the Google account's security settings under Third-party apps with account access. Disconnecting the channel in Rawklip, or deleting its local database, removes the stored data.

Google API Services User Data Policy

Rawklip's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Rawklip uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
